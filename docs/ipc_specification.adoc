== 2. AIDL Interface Contracts

=== 2.1 `ISakshiVaultService.aidl`

[source,aidl]
----
package rajnishkmehta.sakshi.sdk.internal.ipc;

import android.os.Bundle;
import rajnishkmehta.sakshi.sdk.internal.ipc.ISakshiVaultCallback;

interface ISakshiVaultService {
    Bundle ping(in Bundle requestBundle);
    void sendPhoto(in Bundle photoBundle, in ISakshiVaultCallback callback);
    void startVideoSync(in Bundle videoSyncBundle, in ISakshiVaultCallback callback);
    void stopVideoSync(in String fileId, in ISakshiVaultCallback callback);
    Bundle isRecordingSynced(in String fileId);
}
----

=== 2.2 `ISakshiVaultCallback.aidl`

[source,aidl]
----
package rajnishkmehta.sakshi.sdk.internal.ipc;

import android.os.Bundle;

interface ISakshiVaultCallback {
    void onPhotoAck(in Bundle responseBundle);
    void onVideoSyncStatus(in Bundle syncStatusBundle);
    void onCopyDone(in Bundle copyDoneBundle);
    void onError(in Bundle errorBundle);
}
----

== 3. Bundle Data Structures

=== 3.1 `CopyDoneAck` Bundle Keys
[cols="1,1,2", options="header"]
|===
| Key | Type | Description
| `file_id` | String | Unique recording file identifier.
| `vault_uri` | String (Optional) | Content URI of copied file in Vault storage.
| `total_bytes` | Long | Total number of bytes copied.
| `timestamp` | Long | Completion epoch timestamp in milliseconds.
|===
