== 2. AIDL Interface Contracts

=== 2.1 `ISakshiVaultService.aidl`

[source,aidl]
----
package rajnishkmehta.sakshi.sdk.internal.ipc;

import android.os.Bundle;
import rajnishkmehta.sakshi.sdk.internal.ipc.ISakshiVaultCallback;

interface ISakshiVaultService {
    Bundle ping(in Bundle requestBundle);
    void sendPhoto(in Bundle photoBundle, in ISakshiVaultCallback callback);
    void startVideoSync(in Bundle videoSyncBundle, in ISakshiVaultCallback callback);
    void stopVideoSync(in String fileId, in ISakshiVaultCallback callback);
    Bundle isRecordingSynced(in String fileId);
}
----

=== 2.2 `ISakshiVaultCallback.aidl`

[source,aidl]
----
package rajnishkmehta.sakshi.sdk.internal.ipc;

import android.os.Bundle;

interface ISakshiVaultCallback {
    void onPhotoAck(in Bundle responseBundle);
    void onVideoSyncStatus(in Bundle syncStatusBundle);
    void onCopyDone(in Bundle copyDoneBundle);
    void onError(in Bundle errorBundle);
}
----

== 3. Bundle Data Structures

=== 3.1 `PhotoRequest` Bundle Keys
_(Sent by SDK → Vault on `sendPhoto`)_

[cols="1,1,2", options="header"]
|===
| Key | Type | Description
| `file_id` | String | Unique identifier for this photo submission.
| `uri` | String | Content URI of the source photo file.
| `mime_type` | String | MIME type of the photo (e.g. `"image/jpeg"`, `"image/png"`).
| `timestamp` | Long | Epoch timestamp in milliseconds when the photo was captured.
| `meta_<key>` | String | Optional metadata entries, one key per entry prefixed with `meta_`.
|===

=== 3.2 `VideoSyncRequest` Bundle Keys
_(Sent by SDK → Vault on `startVideoSync`)_

[cols="1,1,2", options="header"]
|===
| Key | Type | Description
| `file_id` | String | Unique identifier generated by Camera for the recording.
| `uri` | String | Content URI of the active recording file.
| `mime_type` | String | MIME type of the video (e.g. `"video/mp4"`).
| `timestamp` | Long | Epoch timestamp in milliseconds when recording started.
| `meta_<key>` | String | Optional metadata entries, one key per entry prefixed with `meta_`.
|===

=== 3.3 `CopyDoneAck` Bundle Keys
_(Sent by Vault → SDK via `onCopyDone` callback)_

[cols="1,1,2", options="header"]
|===
| Key | Type | Description
| `file_id` | String | Unique recording file identifier.
| `original_uri` | String (Optional) | The original source URI that was provided by the client for copying.
| `total_bytes` | Long | Total number of bytes copied.
| `timestamp` | Long | Completion epoch timestamp in milliseconds.
|===
